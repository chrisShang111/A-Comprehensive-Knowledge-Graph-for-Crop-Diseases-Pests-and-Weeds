## Data Availability and Repository Scope

This GitHub repository serves as the project landing page for CPKG, providing project documentation, source code, and supplementary materials.

The **Zenodo record is the authoritative archival source for the CPKG dataset**, providing a citable, versioned record for reproducible research.

**Canonical dataset archive:** [Zenodo DOI: 10.5281/zenodo.23524151](https://doi.org/10.5281/zenodo.23524151)

For research, reuse, and reproducibility, users should consult the relevant version-specific Zenodo record and its accompanying documentation.

GitHub-hosted files, where provided, serve as supplementary access points and should be interpreted in accordance with the version and scope documented for each file. The archived dataset version, its associated metadata, and its validation materials define the authoritative release for citation and reproducibility.

## Citation

Please cite the relevant version of the CPKG dataset using the corresponding Zenodo record and DOI. When reporting results, specify the dataset version used in the analysis.
